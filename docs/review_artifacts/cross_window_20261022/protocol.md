竞争解释与判别：

1. 冷窗口排序可直接外推。报告两窗口各自从就绪到最后ACK及总时长；排序改变则否定直接外推，不预设浅额度获胜。
2. 上一轮后到反馈与状态已无作用。核对第二轮首次实际TX的速率、边界前最后控制状态、第二轮收到首个CNP前的TX；即使没有新反馈仍低速可证明发送继承了状态，但不将整个延迟差归因于残留CNP。
3. 只是字节/路径工作量变了。独立核对每轮相同数据/必要ACK端口字节和服务下界；总CE/CNP计数、下界残差不直接当因果分解或可消除收益。
4. 声明后继改变第一轮。按原输入/二进制/拓扑/协议/结果hash只读核对上一轮3个冷启动结果；比较第一轮全部回调与边界前包、速率、控制事件。若不同，保留差异且不能声称只存在跨窗口作用。

准备读原始路由和已核验冷输入。分析仅读observed和公开结果；独立checker才读truth/原件，重建全部工作、实际端点UID关联、路径/端口守恒、逐工作就绪/发布/接收/ACK、NP与RP状态。CNP在边界后生成可能由旧pending和新CE共同决定，不能仅按生成时刻标为新轮反馈。
