简单基线是否已经足够解释

对每个网络配置中三方案做两两比较，共18次整段比较。服务量按模型字节×8/出口速率计算，每窗取最大，再对四个串行ACK窗口求和；数据包头和反向ACK均保留。静态计算只使用输入、拓扑和种子，全部2,284个出口负载与实际逐包发送量一致。代码在执行后实现，只作描述性基线核对，没有前瞻部署策略。

核验与保留的限制

独立检查22,140条数据/ACK路径、116,280次物理发送、94,140次交换机哈希选择、738个工作回调；576个交换出口队列积分和72窗完成分解通过。分析重复四份产物逐字节一致，没有为复现再执行18次网络。全部条件无ECN/PFC/丢包，因此结论只涉及共享路径竞争，不证明拥塞控制长尾或生产收益。

仍只有四个请求；尚无独立请求集、现代通信库的匹配包级/控制语义和硬件校准。这批结果不足以支撑A类论文主贡献，也不支持将更好的配对贪心或新链路指标作为创新。下一阶段应针对简单链路基线解释不了的在线依赖/真实并发问题开展研究，先补语义与独立输入，再验证收益。
