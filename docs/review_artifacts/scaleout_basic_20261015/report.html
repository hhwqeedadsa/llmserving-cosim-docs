范围：8 个逻辑 GPU，2 个 MoE 层，4 轮 ready-KV Decode；计算为显式参考成本，路由为合成数据。A100 是描述标签。结果不代表完整模型、实机 A100、千卡容量或生产 p99。

对照解释：上联降速保持相同请求、计算耗时、远程字节及实际消息路径；双平面固定 NIC 总带宽，因此不预设收益。热点同时改变专家计算和网络分布，不能仅凭耗时增长断言网络拥塞。

EP4 主对照分别位于两个 Pod，结果同时包含副本变化、远程比例和通信本地化，不能归因为纯 EP 收益。跨 Pod 交错 EP4 的共享出口验收另行报告。

独立汇聚探针：64 条消息完成，11489 次 CE 观测，17 次 PFC 暂停，64 条流得到 DCQCN 反馈。CE 是跨端口事件，不能当成唯一标记包数。

中间包丢失后可由 NACK 恢复，源 payload 因重传从 4000 B 增至 7000 B；尾包丢失按预期失败，未误发接收完成。首版服务实验限定无故障网络，未实现通用尾包恢复。

专家成本统一为零的独立诊断中，热点完成时间增加 7.009 μs。这表明该参考条件下网络分布和依赖仍有影响；时间关系已改变，不能从主实验差值中直接相减作为加法分解。
