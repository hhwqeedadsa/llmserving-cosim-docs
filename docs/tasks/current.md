## 目标与边界

允许同一 EP 组的部分成员没有本地 Token：仍给整组提交图，无请求成员处理必要的远端专家输入与结果，不创建虚构请求或填充 Token；没有实际工作的计算节点不计时。请求可在不同时间到达、剩余步数不同，每个 rank 每轮最多调度一个真实 Token，组仍共同完成。覆盖完全空闲成员、纯本地专家计算、某组先结束、空输入，以及输入已耗尽但仍有图/事务/链路包的情况。

补充 EOF、非法协议、后端异常退出和死锁的明确失败与位置记录。没有业务推进事件、没有未来唤醒而仍有等待时报告具体组、图、rank、传输和资源状态；仿真时间上限只作失败保护，不能作为成功完成或固定轮询推进。测试用故障只能在独立测试目标或测试驱动中注入，不能让正式服务静默跳过工作。

允许修改根仓库 `python/moe_ub_cosim/`、`backend/`、`tests/`、`fixtures/` 的本步必要实现、输入及检查，以及根/后端/相关输入 README、`docs/environment.md`、本任务文件。沿用已就绪 KV、合成单层、既有四成员组及最多两个组；不增加 P/D、模型层数、真实路由、校准或网络恢复协议。子模块源码、gitlink 和锁文件保持不变；若发现必须修改依赖的问题，先记录其具体位置与影响。
