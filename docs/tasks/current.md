## 实现要求

1. 用配置及字段关系校验 EP 成员、专家数、Top-K 和专家位置；专家数可以由现有放置表明确推导，也可以采用兼容的显式字段，二者同时存在时必须一致。禁止将固定常量改成另一组配置白名单。
2. 支持非均匀专家放置。每个 Token 的 Top-K 专家合法且不重复；同 Token 同目标 rank 的远端输入按原规则去重，不同 Token 不互相去重；本地输入只计计算，不产生网络任务。
3. 显式使用 rank 到 UB 节点的映射，校验映射完整、唯一且指向实际计算端点。真实发送和接收、操作身份、端口观测和来源关联均必须正确；不能只放宽输入而在后端继续按 rank 编号查节点。
4. 根据实际成员生成和加载图、收发依赖、传输身份和字节范围，保持一份发送一份业务事务、接收仅等待、晚到接收与正常回收。不得重建独立网络实例来绕过映射或成员变化。
5. 保留原输入的含义与回归结果；确需不兼容接口变更时明确 schema 和迁移或拒绝方式。检查整数与字节溢出、引用完整性、重复成员、无效专家及端点类型，在提交执行图前拒绝非法输入。
