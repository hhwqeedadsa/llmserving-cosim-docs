## 目标与边界

复用 LLMServingSim 的请求、调度与 KV 分配接口；联合前端独立控制交接生命周期，避免原生预填充流程内置的流式发送/自动释放。目标容量在交接前预留，源缓存和源组保留到交接成功；后端原子校验和装载涉及两组的图，全部必要接收、发送/事务与图完成后恢复调度，D 不提前解码。模型权重、工作区、通信缓冲和块容量有明确预算与记录。超总容量、布局不兼容、错误分片/图明确拒绝。

允许修改根仓库 `python/moe_ub_cosim/`、`backend/`、`tests/`、`fixtures/` 中本步必要文件，以及相关 README、`docs/environment.md` 和本任务文件。依赖源码、gitlink、锁文件不变；若必须修改依赖，先报告具体原因。不增加多个待交接请求、容量竞争排队、第三个竞争组、占用 P/D rank 的异步重叠、真实路由、模型校准、MLA/缓存转换或新传输协议。M4.2/M4.3 尚未开始。
