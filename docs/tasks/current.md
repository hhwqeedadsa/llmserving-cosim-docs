## 当前步骤

| 项目 | 要求 |
|---|---|
| 小场景 | 8 rank、两台服务器、两个平面、4 个 Transformer 块，一次完整 Decode 执行 |
| 首批输入 | 每 rank 2、4、8 个活跃请求，分别为总请求数 16、32、64；各配三组独立请求与专家选择输入 |
| 生成方式 | 执行前固定规则及输入；同一输入组的较小批次可取预定子集，保留自然不均衡，不按结果选样 |
| 设备与协议 | 各组保持相同参考配置，沿用小场景已验证的原生 STORE/LOAD 与逐包喷洒 |
| 工作量 | 重新生成相应通信与计算并核对容量，不保留旧批次的绝对计算时间 |
| 观测 | 全部 32 个交换机出口采用同等计数和 VOQ/FIFO 记录；小场景详细资料用于研究者核验 |
| 概览 | 按网络资源、传输完成、执行影响三个层次组织，保留不同批次的实际工作量及完成进度 |

当前步骤的交付是九组可追溯正常运行、同口径执行概览、简短现象记录及下一步选择依据。现象记录保留发生条件、证据、性能影响和解释状态；批次增加带来的总时间增长本身不作为性能问题。若已有记录不足以判断某项等待，标明具体资料缺口，不提前补全套观测。
