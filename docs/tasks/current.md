## 实现与验收

- 模型、精度、层范围、注意力/KV 维度和逐层放置显式校验；权重按每 rank 实际专家数加共享权重，KV 不除以 EP。工作区和通信缓冲区计入独立 rank 的预算，并核验通信缓冲区下界与整数范围。

- 非法模型、范围、精度、成员、端点、容量及后端部署不一致在相应启动/提交边界拒绝；不静默截断或重算。旧服务、动态多组及受影响 P/D/多层入口按改动执行回归。
