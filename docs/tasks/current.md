同芯片跨 rank 通过源 rank 的本地准备计算及独立的本地交付完成回调推进，不创建 WQE、不模拟 die 间链路或协议，也不伪造 UB WriteCommitted/TransactionDone。本地交付沿用 ASTRA SEND/RECV 节点表示跨 rank 依赖，使用现有发送槽发起限制；计算准备占用源 rank 的唯一计算槽。跨芯片保持真实 UB WRITE/RTP 事务。

覆盖单层、固定两轮及上一项配置服务入口；本轮不扩展旧来源索引、P/D、跨层组合的输入含义。部署在运行中固定；配置服务仍是一组、一层、每 rank 同时一个请求。场景 YAML 适配、MLA/R1、连续批处理及校准不在本步。
