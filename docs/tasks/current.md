## 自主执行与范围

现有真实路由、拓扑、专家放置、请求与计算成本保持固定，不重新开展代表性、成本校准或硬件队列调查。源端完成语义只核查与本轮时间约束直接相关的模板和记录；不能修改仿真依赖，使期望的约束成立。

Codex 可连续完成源码与数据核对、受限输入准备、分析修正、小型合成检查、基线和简化信息对照，以及有条件的离线恢复与复核。每个环节按证据进入下一步，不为内部字段选择、规则修正或结果为负重复等待用户确认。确有读取或导出缺陷时，在范围内独立修复并小型验证；若缺陷需要改变执行行为或重新仿真，先限制受影响结论并交付其他可完成工作，不自行扩围。

原基线没有使用源端操作结束时间，这是待检验的加强方向，不是已经证明可消除全部歧义。每操作、每出口的最后发送窗口是现有判断器实际使用的候选简化信息，也不预定为必须新增的测量。发现已有信息足够时应接受结果，不继续为维持增量增加协议、模型或测试场景。

原 1024 请求被动输入用于旧结果复算与开发；已有 256 请求被动记录优先用于规则固定后的复核。其他片段仅在现有资料足以提供相应评价时使用。相关窗口与嵌套请求不作为独立统计重复，协议控制、未捕获上游和真实混合操作继续保留边界。准备、判断和评价严格分离。
