## 固定范围与自主权限

主要发现来源为已有 256、512、1024 请求的第 6～8 层正常执行，以及 1024 请求第 3～8 层长段。固定真实路由、拓扑、放置、计算成本、A3 STORE/STORE、原生资源与核内同步。已有 FIFO/64 和轮转/32 仅作辅助敏感性材料，不选取最容易拥塞的档位作为新正常基线，不新增负载或成本调查。

Codex 可在本轮范围内连续完成资料核对、候选选择、重分析、小型测试、必要被动记录与读取修复、有限补采、定向服务对照及初步信息比较。每个环节取得证据后按候选文档继续，不将源码核查、窗口选择或指标修正逐项交回用户决定。最晚消费者须依据当次全部必要完成条件确定，不能只找最后一个数据包，也不能固定旧 rank 和消息 ID。

初步信息比较只针对已核验案例回答现有信息是否足够，允许简单离线规则和最多一种额外信息的受限对照。准备、判断、评价的数据权限分开，不把真值当观测，不以少量精选案例宣称算法准确率或泛化。完整测量机制、协议标记、时钟误差矩阵及 P4 另行决定。

遇到负面结果，先核对是否否定了原解释、是否改变必要完成条件，随后完成其他已选候选及汇总；不调参维持现象。发现可确认的实现缺陷时，提炼小测试并在范围内修复，平台与实验分别验收。缺硬件依据时限定受影响结论，不展开 A3 同步、端点内存或完整芯片建设。
