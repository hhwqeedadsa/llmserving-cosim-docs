# 现代控制器的紧凑因果覆盖

目标：推进真实EP32连续调用所需的宿主扩容准备，替换现代控制器逐节点复制的祖先字典，保持同一128端点Clos研究对象和现有执行范围。本增量不提高rank、连接、事务、回调、窗口或宿主上限，不启动网络、GPU或构建，不改依赖。

原覆盖记录每个原生节点的全部必要祖先，分别标记`applied`和`completed`。新实现以两份精确位集合保存相同信息：applied集合含两级祖先，completed集合只含完整完成祖先。节点身份保持0..65535且只引用先前已登记节点，覆盖不含自身，不从网络或未来推断额外关系。压缩前驱时仍合并同id的较强等级，并同时去掉被任一其他前驱覆盖的项；不能以单一无等级可达性替代。所有先后顺序、回调、源保护与成本保持。

现代控制器调用独立覆盖组件，另以成功插入后的远端/本地计数器替代每次扫描完整节点表。静态完整容量检查和原运行期拒绝保持；错误输入在修改覆盖和计数前拒绝，不截断、不静默忽略依赖。公开CLI参数和输出schema不变。

验收：用独立字典oracle穷举小DAG的两级查询/合并/前驱结果，并覆盖重复等级、菱形、多父、空前驱、自身/未来/未知id与65535边界。两个完整人工回调控制器的计划、初始内存、全部提交/回调/快照与旧提交e55ae45eb1逐字节比较；这些是功能声明，不是网络证据。保留相关现代/批次/容量回归。

宿主比较独立测试进程一次执行相同4096节点人工链，分别记录旧字典与新位集合的结果hash、覆盖对象存储估计、实际峰值RSS、wall及CPU。结果不设性能阈值为正确性断言，不把核心存储、进程RSS或宿主CPU下降换算为模拟推理收益。只对相同输入比较；原生完整EP32执行仍待后续成套扩容和网络验收。

预算根`runs/native_proof_coverage_20261031`：累计600受监控秒、256MiB产物、卷留8GiB；至多5阶段，每阶段120秒/RSS1GiB/地址2GiB。失败保存，不自动扩预算或重跑。只发布user已授权分支；平台验收单独提交，整体目标保持active。
