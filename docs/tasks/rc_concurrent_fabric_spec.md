新增独立公开入口`scaleout rc-fabric-build`与`rc-fabric-probe`，沿用固定原生ns-3及既有RC线格式。2～8条已建立连接，每条一次仅1项WQE在途；最多64操作、64KiB累计WRITE、每GPU最多64KiB且合计256KiB目标内存。独立24位无回绕PSN、目标QP、MSN、WRITE进度、原子重放和重试定时器。同一GPU内存由真实收到的多个QP请求共同修改，fetch-add旧值按实际接收顺序产生。源完成仅来自该连接的实际ACK或Atomic ACK，旧值缺失不能用普通ACK制造。共享同一Fabric、NIC调度、交换队列和ns-3时钟，不以独立运行结果拼接。
