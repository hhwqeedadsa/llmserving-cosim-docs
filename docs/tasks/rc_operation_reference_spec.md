# 操作级RC参考：范围与验收

2026-10-27，起点`62da06f`。本阶段是独立的平台参考增量，不开展研究收益实验。前阶段[载体核查](../../experiments/transport_semantics_audit/README.md)已关闭，不重开single/quad或其他旧网络。

## 目的

在修改原生网络之前，提供可供未来后端适配和独立验收使用的可靠连接（RC）操作状态参考。MRT1保持现状。参考必须区分WRITE确认、携带旧值的Atomic ACK、目标副作用和源完成，不能把两条普通可靠流当真实RC，不能增加模拟器关联字段对应的线上字节。

支持范围限定为一个已建立、同序列空间的RC QP、有限WRITE和64位fetch-add；显式MTU、原子额度和有限重放资源。输入为操作与交付动作，不引入网络时钟、预设到达时刻、排队或性能预测。ACK策略、序号范围、错误和拒绝条件在用户说明中明确。不提供一般READ、SEND/RECV、RNR、完整QP状态机、GPU可见性或硬件服务耗时。该参考是后续完整接入的前置，不把部分功能当已完成真实RoCE。

实现前核对Linux v6.12的请求者、响应者、完成者和包头定义。只有在源码支持时才纳入相应完成规则；有歧义则显式拒绝，不能凭假设补齐。不得通过收到普通累计ACK推定丢失的原子返回值。重复原子只能重放保存的旧值；重放资源有限，超出支持边界必须显式处理，不能无限缓存。

## 固定来源与限额

只读GitHub公开Linux v6.12：一次commit查询及逐层Git tree取得固定commit、路径和blob；既有req/resp/hdr仅在新固定blob核hash后复用，补取comp/opcode及必要常量定义。最多20次HTTP、累计2MiB响应，每请求总截止10秒、单响应256KiB；同URL失败不重试，不下载内核/依赖树或执行上游模块。若目标目录无法在上述限制内锁定，保留失败，不自动增加请求或改用浮动版本。

工作目录`runs/rc_operation_reference_20261027/`。累计1200受监控秒/256MiB新增产物，单命令60秒、RSS1GiB、地址2GiB；小型独立C/C++语义核验编译允许单次120秒/RSS1GiB/地址2GiB、最多两次编译（源码/编译错误保留）。保留8GiB空闲和2MiB/10秒管理额度。零新网络仿真、原生后端构建、GPU、依赖升级、大型下载和push。

## 验收

1. 来源：固定Git路径与blob逐hash核对，不将tag或下载成功当固定tree证明；原获取失败和旧来源边界保留。
2. 平台：不导入experiments/tests/fixture；提供可复用的公开Python接口及可复制的独立小例。明确这是状态参考，不与ns-3联动，不输出微秒或收益数字。
3. 语义：WRITE分段、部分交付、正常完成；fetch-add旧值/64位回绕；重复请求、丢回复后重放、有限重放覆盖；普通ACK与Atomic ACK区别；同QP顺序、源保护和原子额度；不支持或非法输入应拒绝。
4. 独立性：固定上游的少量原函数可在显式stub环境中执行时，保留未修改函数和stub的清楚边界，与Python参考对照；这只证明所执行分支，不能冒称运行整个RXE/内核。否则采用独立手工状态表，并降低证据等级。
5. 搬迁：复制源码/小例到新目录、空cwd运行，摘要一致；包与逐成员hash支持离线复核。仅检查受影响功能，不运行旧网络或完整MoE。

功能完成与研究创新分别验收、提交。完成本阶段不能宣称MoE提速、宿主加速、完整RC接入或千卡验证；两项主创新继续待证。
