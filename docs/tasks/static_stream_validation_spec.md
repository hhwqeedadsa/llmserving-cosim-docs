# 会话内固定传输声明的校验复用

平台增量，基线`057e40a`。依据已完成的[重复准入剖析](../../experiments/session_admission_profile/README.md)，只优化重复的纯Python streams子校验，不评价提速或论文收益。平台验收与后续性能实验分开提交。

## 接口和不变量

`NativeTransactionSession`及两个公开入口`modern-deepep-native`、`rdma-transaction-session`新增默认关闭的`reuse_static_validation`/`--reuse-static-validation`。仅在同一个会话内保留一份已成功校验的完整topology、protocol及派生streams声明的不可变、保留类型的键；不用对象身份、普通Python相等或仅用摘要判断复用。整数、布尔、浮点、容器类型变化都不能命中。只为内建JSON类型构造键；其他类型和递归输入回退原校验，不接受未经检查的输入。键不保留调用者可变对象；静态检查失败不能替换此前成功键，不共享全局缓存。

动态候选仍完整复制和校验：连接基础字段、窗口、注册、依赖、全部历史操作/祖先/写顺序、应用寿命、自服务、源保护以及C++准入全部保持。静态子检查通过而后续动态检查失败时，可保留该合法静态键，但不能提交候选、发送COMMIT或改变会话状态。新选项不传入原生协议，不改变控制消息、包、路径、排队、回调、内存和任何模拟时刻。关闭时不生成额外产物；开启时仅生成`static-validation.json`宿主诊断计数，算法不得读取它作决策。

## 预定验收

1. 类型安全、嵌套修改、输入别名/快照脱离、失败原子性、独立缓存与动态非法操作拒绝；相关streams/transactions/session/modern/CLI回归。单位检查不启动网络。
2. 固定六次健康小网络：现代入口默认/复用；事务入口默认/复用；复制源码根、空cwd、复制O3运行时的现代复用/事务复用各一次。现代使用公开两rank两调用`input-expert-costs.json`，事务使用公开`session-program.json`的原子返回与后继写。两种拓扑均由公开命令生成。不注入新故障，不修改通信、计算或执行限额。
3. 每次完成后核对完整result和control，现代还核完整执行快照；同根不规范化字段，迁移仅允许已核hash的加载库根路径和库路径枚举多重集合。独立重数实际回调/操作时间、目标原子旧值及最终内存；现代使用已有功能审计器，绝不以缓存计数替代行为检查。至少四类结果/计数篡改必须拒绝。
4. 逐成员hash归档与复制源码/空cwd离线复核；上述最后两次就是迁移网络，不另开恢复网络。保存实际命令、失败、退出状态、八库身份与13依赖检查。无新构建、安装下载、GPU、依赖变更或push。

任一网络或完整行为对照失败，保存并关闭余下网络额度；不扩大预算或重跑失败网络。单元/离线检查的修复与首次失败保留。结果不支持实际加速、GPU校准、千卡泛化或两项创新已经成立。

### 执行前置核验脚本更正

首次默认现代网络成功，但在完整行为核验开始前，脚本误将包含6项系统库的`loaded_libraries`全列表要求为8项，因而停止。实际8项ns-3库均来自登记运行时，网络没有失败。保留首次driver/ledger/源码快照；仅更正fixture对ns-3库的筛选及迁移路径比较，系统库名称/相对枚举顺序仍严格保持。平台、原生运行时、输入、接受条件和总预算不变。先离线核验已成功默认网络，再继续原定尚未执行的5个条件；不重跑该网络，不追加第7次。后续网络或完整行为对照如失败，继续按原停止规则执行。此更正不把错误的脚本条件写成通过。

随后现代默认/复用的完整行为严格相同，第三个事务默认网络亦成功；其核验器误读`target_events.operation`字段，实际格式为`connection/sequence`。第二次停止不涉及网络差异；保留该失败及对应源码，修复为按连接/序号核对每次实际副作用的帧、时刻与去重，并先对既有事务结果离线复核。只在该核验通过后执行原定未开始的3个条件，不重复前三次成功网络，不变更平台源码、运行时、输入或总预算。两次脚本错误不能写成原始检查通过。
