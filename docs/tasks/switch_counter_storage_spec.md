# 按实际端口保存交换机计数：平台增量

2026-10-27，起点 `6996c49`。只完成一个有界的平台工程改进，不创建研究实验，也不以它替代两项尚未成立的论文创新。

## 行为

原生 `SwitchNode::m_bytes` 按入口、出口、优先级保存32位计数；1025×1025×8×4=33,620,000字节/交换机。`SwitchMmu`的线性数组不是这个开销来源。保留全部加减、丢弃核对与原有控制优先级计数行为，不删计数或断言，不改包、队列、ECN/PFC、RNG、路由、仿真时间、完成或恢复。

协议v1/v2可选 `switch_counter_storage`，且仅允许字符串 `legacy_dense` 或 `port_dense`；缺省为前者。Fabric在全部物理接口安装后、任何流量前初始化计数，前者1025槽，后者使用包含slot0的实际 `GetNDevices()`；仍受原生最多1024物理端口约束。底层默认构造不先分配完整矩阵；非Fabric上游调用第一次访问时补默认1025槽，不能降低紧凑模式峰值后再假称没有预分配。初始化只允许一次，越界在访问前拒绝。

显式选择模式才新增结果 `switch_counter_storage`，列出每交换机实际槽、存储槽、载荷字节和非零计数，及总字节/模式/范围。缺省结果结构保留。载荷字节不是完整RSS：MMU、对象、连接、路由、包和观测另计。Python准入使用所选矩阵大小及既有256MiB预留；该估算不是完整内存上界，实际RSS/地址监控仍约束整个进程。

修改锁定原生依赖，从 `749794e` 建独立任务分支，依次保存ns-3、ASTRA、LLMServingSim及父锁/gitlink；只本地提交，并保存以原固定提交为前提的增量bundle。UB隔离，不升级依赖。

## 固定验收和停止规则

开始执行前本规范与任务页先提交。标准库准备器生成独立的新输入，通过公开CLI执行，零GPU/下载/安装/push。旧关闭研究条件不重开。

最多8次网络，每个条件只运行一次，不因失败改变输入、扩大预算或重跑：

1. 新8端点、双rail共享Agg功能输入：沿用公开拓扑参数，4条64KiB流，ECN阈值4/8KiB、所有节点完整包采集与队列统计。分别执行已保存旧二进制默认模式、新二进制默认、显式legacy、port共4次。预期确有共享排队/CNP；若没有只报告范围不足，不加流量。
2. 同一输入另设一条实际Agg–Core链路在12us永久关闭、2us后更新路由，使用现有go-back-N（RTO100us，最大400us，重试4次）。显式legacy/port共2次。分区或失败保留，不承诺成功恢复，不调故障时间找正例。
3. 新1024端点、8Pod×16服务器×8GPU，32ToR/16Agg/2Core，所有链路200Gb/s/2us；256组EP4、一次All-to-All/local/All-to-All，每对每阶段384B、local200ns。显式legacy/port共2次。只采所有端点的包头及全网端口/队列统计，最多100,000采集事件。此为短合成功能容量检查，非完整MoE/EP1024/真实请求、硬件时延或研究速度实验。

逐项比较所有动态结果（仅剔除模式/计数存储元数据、经hash确认的加载路径），包括包身份/顺序/时间、队列事件及积分、所有端口、ECN/PFC、反馈、工作回调、连接末态、故障和完成。不容许按任意排序消去差异。计数快照除存储槽/字节外相同，排空时优先级3计数为零。独立按物理degree+1复算分配；检查小场景实际逐跳包的路径/串行传播、收发守恒、队列积分。非法模式、bool/null、过窄预算及原生初始化/越界应拒绝；4类以上证据篡改拒绝。
