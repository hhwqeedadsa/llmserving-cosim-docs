4,264次健康DATA包交换机经过全部配对，无缺失，5处驻留变化累计+410ns（含一处−37ns），不等于业务损失。另3条消息的接收不变、ACK分别晚150/207/1ns，实际ACK源发送时刻相同、路径驻留分别增加同等时间；原阶段余量7626/7727/1841ns未耗尽，所以健康最终完成和全部阶段释放不变。首次解释脚本误要求各rank到达也不变而失败，保留日志，修正为保留到达、核对实际最大释放时刻后通过。零网络重跑。
