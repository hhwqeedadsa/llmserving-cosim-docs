延迟副本正常时跳过备用执行，与无副本的完整逐包记录一致；但备用KV仍预留10,092,544字节。故障时相对无副本缩短3.735µs（2.73%），仍执行双份通信和声明计算，整体收尾晚219ns。第一层Dispatch原尝试86.698µs接收齐，源确认从90.702晚至90.921µs；尚缺独立端口/负载对照来证明具体干扰成因。

这是成熟基线对照及仿真系统功能，不是新算法收益。两层、一个Decode步及声明成本不能外推为完整671B请求、满载集群、GPU实测、吞吐或经济收益。模型/KV预置、数值等价和其他独立健康任务仍未验证。
