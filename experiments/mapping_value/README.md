# 历史实验：端网映射的信息价值

本目录保存早期 v0.4 参考模型下的映射价值实验，检查完全正确的操作与端口关系，能否帮助区分准备变慢、网络服务变化及其影响。它与后来的 A3 资源修正和网络机制探索属于不同阶段，不能将旧模型结果直接作为当前部署的结论。

当前研究已经转入[Scale-Up 性能问题与被动诊断能力](../scaleup_issue_screening/README.md)，三个目录的关系见[实验总索引](../README.md)。本目录保留原代码、配置、结果和复现能力，不承担新的任务进度。
