# 真实路由时间对齐：本轮结果与边界

本轮只完成一个网络条件。首个检查器误用可缺省的内部任务编号而失败，后续31条件按事前规则停止；原失败、冻结输入和预测保持。修正检查器后仅离线核验，不重跑网络。没有测得对齐收益，也没有证明新创新。

八个用户确认来源的完整请求，固定首八步/layer3，EP8/八台单卡服务器。每个变体合计6,221,824B网络token字节，434次WRITE及136个本地节点，56条持久连接；16个输入的逐连接总字节严格一致。激活BF16、每rank专家1000ns均为声明。

首条件完成全部570节点，应用及物理排空均为310.233us；3472个源数据包、33,484次含ACK/CNP的物理发送、2个CNP。八轮任务依赖、每流连续序号、数据/ACK包尺寸、端点收发、ECMP投影对应的全部端口字节一致。六类篡改拒绝。队列积分由原生全端口summary保存；端点捕获不能独立重建所有交换机瞬时队列，不冒充逐跳捕获。

该单条件中平均链路模型误差-2.69%，逐步链路模型误差2.56%。这只是一个输入下的预测核对，不能推广成准确率、对齐优化收益或强基线被超越。

冻结的普通逐步链路模型预计offset相对aligned变化约−0.37%（100G）、−0.69%（25G），均小于事前10%筛选门槛。但预测不代替未执行的31个包级条件，因此真实对齐效应仍未验证。不能据此否定所有模型、层或请求的时序作用，也不追加层/窗口/seed搜索保住假设。
