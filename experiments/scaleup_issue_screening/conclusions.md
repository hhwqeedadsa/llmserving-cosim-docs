# 研究结论与当前取舍

当前转入按网络机制覆盖性能问题、诊断能力与采集成本的完整探索，[方案](plan.md)已经确认，新实验尚未执行。下面仅归纳继续有效的历史判断，不将本轮预期写成发现。

## 已有判断

| 已有工作 | 可以保留的判断 | 当前取舍 |
|---|---|---|
| 初始正常运行与 C1 | 供数准备和后续完成差异确实存在；原生资源及依赖会改变等待组成 | 保留基线与核验工具；C1 的发送队列和同步缺少充分硬件对应，不继续围绕该局部分量立题 |
| 固定额度的队列组织 | 状态等待大幅减少未产生等量业务收益，数据推进和实际完成条件也会变化 | 不把局部累计等待直接当成可消除损失，不再追加原 worker/额度/轮转实验 |
| N1/N2 网络案例 | 交换机中的等待及 N1 的有限业务作用已经核验；局部服务改善后其他条件可以接替限制完成 | 作为网络事实与依赖检查参照；不以两个出口的结果代表全域机制或否定被动测量 |
| 操作结束边界 | 源端结束与简单计数未消除部分交叠歧义；当前判断器只需最后发送窗口即可利用理想关系的增量 | 保存一个具体信息不足案例，暂不围绕它建设完整映射恢复或时间同步系统 |

完整数值、原始解释及各自限制保存在[历史结论](https://github.com/baoy21/moe-ub-cosim/blob/b345694fbc2faed8feebb425d43c60f765f7eee9/experiments/scaleup_issue_screening/conclusions.md)及[四个历史分区](archive/README.md)。原始结果未改算。旧完成状态仅表示当时任务范围完成，不表示当前三类问题已经被充分探索。

## 本轮研究判断应回答什么

本地竞争、下游传播和多平面推进分别检查到了什么；数据是在发送前等待还是进入交换资源后受阻；现有观测能否区分不同原因；在有限状态和上报预算下，哪些证据可以保留，哪些判断会丢失。

本轮结果形成后，按研究问题在这里归纳机制覆盖、诊断增量和成本，而非按运行日期追加日记。已排除、受控验证、未覆盖和有用候选分别说明。最多推荐一至两个具体方向，并给出相对已有能力增加了什么、为什么值得继续及还缺哪项验证。

真实路由、拓扑和计算趋势继续固定，不反复转向基础输入校准。不以新场景重要推定任何方法有效，也不要求必须找到前所未有的瓶颈；合理基线已经足够或较低成本方案没有收益时，正常报告结论。
