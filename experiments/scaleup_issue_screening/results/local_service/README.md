# 本地竞争与服务不足

[四档正常来源](normal.json)保存各 2688 个声明交换出口的首次筛查；[精确正常复核](normal-exact.json)补充 1024 请求短段的真实服务和逐包等待。补采覆盖这些出口及其链路对端共 3584 个端口，范围为 `[0,394911 ns)`，19,123,879 条事实完整无丢弃；原 2688 出口报文/时刻及 8,082 份原记录[等价通过](capture-equivalence.json)。

正常运行有 140 个持续至少 1 μs、峰值至少 8192 B 的声明范围排队事件；没有低于名义速率的服务事件或实际信用检查失败。预选 `768:6` 在 2～12 μs 的 178 个相关报文，实际到达至发送等待累计 448102 ns，其中出口忙碌覆盖 447519 ns（99.87%）；报文最大等待 7400 ns。这支持短时来流竞争，不能把累计等待等同于业务可缩短时间。

另一预选共享出口 `768:18` 的 1～4 μs 共 27 个报文，最大实际等待 77 ns；相邻有面积的窗口并非持续拥塞。两种状态均保留，不以队列面积大小替代机制。
