# 多平面推进差异

正常来源复用[四档完整筛查](../local_service/normal.json)。在物理角色、对端相同且整段实际发送字节相差不超过 10% 的出口对中，1024 请求短段最大的两组累计字节 90% 进展差分别为：

| 对端 | 出口与平面 | 实际发送字节 | 90% 进展窗口终点 |
|---|---|---|---|
| 78 | `799:14`（3）、`801:14`（5） | 451260 / 423400 B | 325 / 270 μs |
| 90 | `805:10`（2）、`809:10`（6） | 452268 / 415124 B | 317 / 264 μs |

55、53 μs 差值不能直接称为平面服务失衡。整段相近工作量仍可能跨阶段分配不同，后发的一小批工作也会改变 90% 终点；需复核实际阶段工作、到达时序、服务和必要完成条件。未假定请求随机喷洒使各平面均匀，也未以这两组代表尾延迟分布。
