基线`87d8eb8`，平台阶段；公开入口和输入约束见[用户示例](../../examples/scaleout_causal_waves/README.md)，事前范围及最后一次长图验收补充见[规范](../../docs/tasks/causal_wave_spec.md)。本阶段不提出优化算法，也不以功能验证替代现代GIN或论文贡献。

`run.py`仅执行三个主网络：人工两组EP2/两步、64个原节点，包含接收本地前驱、零计算及未被计算后继引用的SEND；普通传输、正常选择重传、单数据丢失选择重传分别核验。每个条件16写/36本地工作，含4个零时长组结束join。正常/选择正常结束均57,998ns，故障62,845ns；故障有实际快重传，源包32→33/有效负载16,024→17,024B。它是功能人工例，不代表生产损失或新方法收益。

其中接收数据在6,621ns到达，但本地前驱到20,100ns才完成，原RECV不能按接收时间提前结束。故障组下一步确有延迟，另一组完成仍50,440ns，未增加跨组屏障。全部端点/中间链路包、真实ACK、接收前缀、队列信用、本地串行、原节点完成及全部组结束逐项核对。

第四次在已核验v1快照的新Python源码根、空cwd通过公开命令转换并执行完整48层/两步图。来源是历史Qwen3前端group0，保留7,284个原节点、2,090个消息、全部时长/依赖/路由选择；rank0/1/512/513投影0/1/2/3，修改物理部署和连接模型，独立逆变换核对除声明投影外所有字段相同。生成5,311个工作（2,090写/3,221本地），12条QP跨轮保留；实际2,878源包/18,948,096B，模拟结束2,666,303ns。全部11,512条端点事件完整，27,192次物理链路发送按端点实包和独立最短跳数核对，未还原实际逐包ECMP路径。此例无ECN/PFC，不是拥塞收益证据。

该长图没有执行张量数值、现代通信库、GPU可见性或匹配硬件；没有重跑原千卡场景，没有与原600秒超时计算加速比。原生程序仍复用前阶段明确hash的stream程序及八库，包不包含该运行时，不能声称独立从零构建或跨机器可运行。

142项相关Python检查包含完整48层转换和16类非法图/绑定。第一版测试把单向等待误当成环，修正为实际跨rank环后通过，平台实现无需改变；失败保留。`audit.py`仅用标准库，独立核对实际包/原图，7类篡改均拒绝。`checks.py`再核全部长短图、本地槽及8类不安全归档写入前拒绝。所有成功网络均未为审计器改动重跑。
