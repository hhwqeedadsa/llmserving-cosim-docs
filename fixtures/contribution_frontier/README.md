# 贡献就绪诊断检查

工具按每个调用的全部预期贡献取最大值，区分单份提前与完整集合提前，保留并列最后贡献；同时检查实际FIFO、必要门限和赢家缓冲寿命。只读公开命令见[说明](../../docs/contribution_frontier.md)。

`tests/unit/contribution_frontier_test.py`的人工整数记录不是新网络。它检查9个测试方法：公开CLI与目录保护、快但非关键的备用、仅观察无helper、修复最后贡献的有效前沿、并列尾部、缓冲提前释放/同刻未知、未捕获与本地结果、9类非法覆盖/赢家/传输记录，以及组门限/FIFO分开。收益为正与为零的输入都覆盖，不将研究结果设为必须获得正收益的断言。

本轮公开命令读取上一轮独立生成人工输入和四份真实路由输入的两个128端点Clos结果，均先通过完整`rdma-check`核查；人工427份、真实431份输入文件SHA256前后一致。没有构建、下载、升级或新网络；结果解释和完整证据入口见[研究结果](../../experiments/consumption_value/README.md)。
