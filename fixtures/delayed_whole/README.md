# 延迟完整副本平台验收

接口见[完整说明](../../docs/whole_call.md)与[128端点Clos示例](../../examples/scaleout_whole_call/README.md)。

[执行前证据](pre-network.json)包含62项不同CPU检查、纯原生ns-3时钟检查、四份既有128端点Clos结果的只读复核，以及四类建网前拒绝。`clock_check.cc`只创建定时事件，不创建网络设备、Fabric或ASTRA实例。新服务与时钟检查分别隔离编译，复用锁定依赖，旧服务及8个ns-3库未变。

CPU检查包括：完整primary提前完成后跳过副本；原生截止唤醒才能启动；同刻按已知完成前缀决策；多call按组顺序提交；已启动的输家真实收尾；原始LLMServingSim请求的KV预留、实际启动及释放；跳过者无ITL、无执行完成；伪造完成、定时事件、KV字节或释放时间被拒绝。定时器替换在修改状态前预留后续触发记录预算。

执行前证据不代替新网络验收，也不宣称收益或算法创新。初始完整专家和等价ready-KV仍为声明，不验证数值或模拟建立成本。首次旧后端检查的报错措辞断言不符，以及首次收据脚本的语法错误，均保留原日志，修正后通过。
