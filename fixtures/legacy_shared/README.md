## 复核

从仓库根按公开操作生成完整输入，并运行四个新目录。保留本机原件时，可不启动成功网络执行：

```bash
PYTHONPATH=python python3 -B tests/integration/check_legacy_shared.py \
  --root runs/legacy_shared_20261031 \
  --backend-build runs/legacy_shared_20261031/build-v2 \
  --output /path/to/new-verification
```

检查器面向本组四目录，包含6次Fabric前拒绝的原生调用；若需同时核对旧二进制未改，显式提供`--prior-frozen`。仍须监控器包裹并保留预算，输出必须是新目录；源码hash变化时检出对应提交，不能改旧收据。

本目录JSON是输入快照，plan/binding路径属于准备程序生成的完整目录，不可直接把本目录当执行输入。复现调用[prepare.py](../../examples/legacy_shared/prepare.py)，不需取得旧真实路由或旧运行原件。大结果、二进制、库不随fixture提交。

真实来源双EP32研究仍需独立冻结来源划分、直接故障/共享路径及成熟恢复对照。平台功能完成，整体研究仍进行中。
