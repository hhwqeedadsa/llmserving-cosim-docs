# 本地失效端口剔除的功能验收

平台基线`7077530`。本阶段为交换机间永久链路失效增加显式`local_failover.mode=live_ecmp/1`，只从原等价候选删除本交换机实际已断的端口；默认不启用。用户配置和公开命令见[示例](../../examples/scaleout_live_ecmp/README.md)，要求及预算见[规范](../../docs/tasks/live_ecmp_spec.md)。这是经典强基线，不是论文创新或实机恢复性能。

## 实际证据

共六次人工小网络，在同一原生ns-3中运行持久连接、实际接收/ACK、选择重传及本地任务。各输入均为8个GPU标签、10交换机、单plane Clos；没有执行GPU或完整MoE。4,000ns故障、16,000ns全局改路是声明功能参数。

| 条件 | 完成ns | 本地丢包：清队列 / 转发失败 | 用途 |
|---|---:|---:|---|
| 旧程序、默认 | 118416 | 7 / 16 | 默认参考 |
| 新程序、默认 | 118416 | 7 / 16 | 全字段兼容检查 |
| 单故障、显式本地剔除 | 40768 | 7 / 0 | 旧等价活出口继续转发 |
| 两故障、交错全局更新 | 41340 | 7 / 3 | 不重装本地坏口、不提前远端通知 |
| 0ns故障且0延迟改路 | 24838 | 0 / 0 | 首包前收敛边界 |
| 新源码根、空cwd、空候选路径 | 52322 | 7 / 31 | 无候选仍实际丢包及公开流程 |

最后一例仅更换反向线上端口，使ECMP经过有唯一已断下跳的交换机，不能与主例作性能对照。默认旧/新完整结果仅有八个同hash库路径的`bin/../`拼写不同；逐库核身份后仅规范化这些路径，其他字段全部相等。原始结果不宣称逐字节相同。

`audit.py`不导入平台路由算法，按拓扑独立BFS、全局已收敛事件和实际本地down重建候选，并复现固定源码Murmur哈希核对实际enqueue；不能拿晚于更新的TX倒推当时选路。复用既有平台`selective_repeat.audit`核所有真实数据/反馈字节、源前缀、乱序缓冲、物理收发、队列积分、MMU和完成回调。重建计数只作辅助，必须匹配实际包。

`verify.py`离线复核全部六条件、全部故障端口之后无TX、九次native分配前拒绝、六类证据篡改和八类不安全归档拒绝。与v1快照的五条件审计完整JSON一致；加强版只新增断言，既有报告一致。详情见[核验](verification.json)、[新根流程](recovery.json)与[资源收尾](closeout.json)。

## 工具与来源

- `build.py`：有界增量编译Fabric及受header布局影响的stream/transaction消费者，复用显式固定对象/八库；不是从零构建。旧archive、程序和库均核hash，固定依赖未改。
- `run.py`：五个主条件，所有输入先preflight，最后网络名额留给新根流程。
- `native_reject.py`：九种非法策略直接调用native，要求分配前拒绝且不写结果；不执行网络。
- `checkpoint.py`：有限体积源码/证据包，先校验全部成员类型/路径/大小/hash才写恢复目录；不打包native程序或八库。
- `fresh.py`：从已核v1快照的新Python根、空cwd调用公开拓扑和网络命令，使用第六也是最后的实际网络；随后只离线复核。
- `verify.py`：实际结果完整复核、篡改和归档负例；不启动native。

本机阶段`/dev/shm/moe-live-ecmp-20261024/`保留全部命令、退出状态、编译/准入/审计失败和原件。持久源码/证据包位于`runs/live_ecmp_checkpoint_20261024/`，含每成员hash；native程序、原生头文件及八库是明确外部hash输入。失败原因依次为固定C++API引用类型、示例缺DCQCN参考、库路径拼写比较、run记录缺失、主例没有覆盖空候选实际包、最终比较的整数/字符串JSON键。修正源码或离线检查后分别保留新监控，不重跑成功网络，不扩大预算。

重做本轮须建立新的明确资源阶段，不能向已经关闭的六次额度追加网络。按规范先审阅脚本和外部输入，再通过公开命令运行；历史构建驱动和本机tmpfs路径不能当研究依赖。新的真实路由研究使用自己的配置、程序和预算，不导入这些fixture。

立即本地动作没有额外检测/编程成本，没有新绕行、源通知、恢复链路、现代GIN或校准。下一研究应在完整保存的应用依赖下判断这条经典基线之后的残余损失；小例完成时间差不能支撑应用收益或A类论文主张。
