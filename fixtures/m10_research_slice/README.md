# M10 首轮研究切片与用户流程

本目录保存 M10 首轮研究交付的验收摘要，最终结果见 [checkpoint-final.json](checkpoint-final.json)。统一命令、小例、隔离安装、目标重采样和唯一一次正式目标重放均已通过。大图、原始事件、真实来源及生成观测留在本地忽略目录，不随 Git 提交。使用方法见[用户指南](../../docs/user_guide.md)，开发范围见[当前任务](../../docs/tasks/current.md)。

## 已完成的检查

- [用户流程检查点](checkpoint-user-workflow.json)：统一命令、独立构建、首轮冻结和迁移、无 site-packages 的离线采样与后端重放、公共观测单独校验，以及坏输入拒绝。
- [隔离安装与原采样检查点](checkpoint-isolation-and-baseline.json)：新检出、新虚拟环境和新后端下的 47 条用户命令通过；目标原 1 µs 采样的六张研究表与历史结果一致。

小型完整服务包含 333 个节点、99 次交付（69 次 fabric、30 次 local）。冻结前与重放均结束于 35538 ns，原始执行记录和研究表相同。将实际链路传播时间从 20 ns 改为 320 ns 后，执行终点变为 90885 ns；135 个计算节点中，97 个的开始时刻改变，计算耗时本身均未改变。这项检查验证通信依赖反馈，不是硬件校准。

目标 10 µs 重采样通过导出守恒和独立窗口聚合比较：9461897 个非零端口窗口、2910987 个归属窗口与原 1 µs 结果独立合并后的记录一致，3741764 次网络交付、10058044416 B 唯一业务量和全部端侧/操作/传输记录不变。

正式重放的 11 类执行记录与原首轮一致，包含 7655238 个节点、3741764 次网络写和 25930 次本地交付。核对全部 16128 端口的审计及 48384 份逐包/队列/来源文件，以及六张研究表。压缩表示不同的文件逐条比较逻辑记录；没有将压缩头差异当作执行差异。两次执行终点同为 75323418 ns，网络只初始化一次，67198929 次物理包发送/到达相等并排空，128 rank 活动资源及图/传输/包来源退出清零。

隔离检查复用经过核验的本地 Git 对象和系统 Python 包，未继承旧 build/runs/.venv。它证明当前 Linux 上的可重复用户流程，不代表跨发行版验证或从公网重新取得所有私有依赖。

## 自动检查入口

`tests/integration/check_user_workflow.py` 覆盖已有后端上的小例完整流程；`tests/integration/check_user_install.py` 从隔离检出安装、构建并执行 README 操作。两者的具体参数以 `--help` 为准。

`tests/integration/check_slice_acceptance.py` 串行组织原采样比较、隔离安装、新周期采样、唯一一次正式目标重放及最终比较；`tests/integration/check_slice_target.py` 流式比较记录，避免展开数十亿零窗口。自动检查是维护工具，普通使用者按 README 中的 `moe-ub` 命令操作。

实际命令、工作目录、退出状态和日志位于 `runs/v03-research-slice/checks/`，各公开运行的资源报告位于其 `logs/resources-*/probe.json`。检查点 JSON 中的本机绝对路径用于追溯，不能作为另一台机器已经具备相同产物的证明。

## 研究范围

固定目标为 128 rank、1024 请求来源、61 块的完整首轮，实际执行区间为 0～75323418 ns。原观测声明到 1000000000 ns，尾部零窗口不代表又执行了后续轮次。重放直接装载图，由本次 UB 完成事件驱动依赖；它不运行路由导入、Scheduler 或重新构图。

当前未验证完整 64 步服务、后续自适应组批、任意时刻网络快照或目标硬件绝对时延。CANN 和计算仍保留参考模型状态；真实路由来源、功能等价和硬件校准分别记录。
