# 多请求 KV 交接与独立 EP 组竞争

M4.2 复用 M4.1 的 `cosim_tiny_moe` 合成单层模型、固定五阶段计算和 BF16 KV。P 为 rank 0～3、D 为 rank 4～7，独立组为 rank 8～11。当前前端明确要求这三个四成员组，每类请求最多八个；每个 P wave 最多 16 个实际 Token，D/独立组每 rank 每步一个 Token。模型与时序没有硬件校准依据。

请求 501/502 同时在 P rank 0/2 到达，各预填充八个 Token、生成三个输出 Token。预填充路由均指向各自本地的两个专家，使两请求在 121000 ns 完成并入交接队列；同时完成按请求编号确定入队顺序。两者目标均为 D rank 5。该 rank 总预算为 2323968 字节：权重 2233856、工作区 65536、通信缓冲 8192，余量仅容纳一个 16384 字节 KV 块。其他 rank 仍为 4 MiB。

每个请求有效 KV 为 8192 字节，K/V 各 4096、按 3072/1024 分块，共四次ns-3-UB 写。容量预留覆盖该请求直到最后一个解码输入所需的块，未计算位置只是占用容量，不作为有效 KV 传输。这避免接纳后又因增长抢占另一个已接纳请求。没有模拟共享 HBM 带宽。

队首交接要求源、目标组都可提交且目标容量充足。满足条件时优先交接；否则源缓存和 P 组保留，D 继续实际解码以释放容量，不被一个待交接图占用。交接成功后源块释放、D 接纳请求并复用目标块。只有全部源请求交接完成，P 组才能接纳下一轮预填充。组内不异步重叠 KV 和计算，独立组不受这个保留影响。

## 共享网络对照

十二 NPU 按奇偶连接交换机 12/13，接入 400 Gbps、交换机间 1 Gbps，各链路延迟 20 ns。所有对端路径及 RTP TP 显式固定。KV 从偶数源 rank 到奇数目标 rank 5，独立组的 rank 8/10 在 115000 ns 到达并向 rank 9/11 发 Dispatch；共同经过交换机 12 的端口 6。独立组各请求有三步显式解码路由，给定 KV 已就绪。

| 场景 | KV 次数 / 写次数 / 业务字节 | 服务完成（ns） |
|---|---|---:|
| queue：只运行两个 P/D 请求 | 2 / 16 / 20480 | 365024 |
| independent：只运行独立组 | 0 / 24 / 12288 | 257656 |
| overlap：两者重叠；来源开/关、不挂观测、重复各一次 | 2 / 40 / 32768 | 427163 |
| staggered：独立组到达改为 600000 ns | 2 / 40 / 32768 | 742656 |
| roomy：只运行 P/D，D rank 5 增加一个容量块 | 2 / 16 / 20480 | 365458 |
| late：只运行 P/D，130000 ns 再到达一个预填充请求 | 3 / 24 / 30720 | 560808 |

queue 的第一个 KV 在 195784 ns 完成，D 两步结束后于 243012 ns 才为第二个请求预留目标并交接。overlap 的第一个 KV 于 221927 ns 完成，D 同时开始，均后移 26143 ns；第二个交接从 279599 ns 开始。源缓存在等待期间始终保留。roomy 按 P、KV、KV、D 顺序，验证在有空间的边界优先处理交接；更多容量不保证本输入总时延降低，实际结果原样记录。

EP 包 UID 1 在 120035 ns 入队、124754 ns 出队，跨越 121000 ns 的首个 KV 图启动；后端没有重建网络或清除旧队列。KV 业务包在选定物理 FIFO 的平均等待从 345.25 ns 增为 1545.75 ns；这只是该 FIFO，不包含 VOQ、信用等待等全部排队。逐包范围、逐窗 KV/EP 字节和原生 Port Tx 日志均核对。错开运行无 KV/EP 混合窗口，P/D 完成时间恢复 queue 的结果。

九次正常运行、八项预期失败覆盖容量不足以容纳单个完整请求、错误映射、重复身份、缓冲不足、坏 KV 大小、末成员图损坏、部分组和忙碌组交接。输出保留容量快照、FIFO 顺序、实际图与事务、TTFT/ITL 和异常位置。运行入口见 [后端说明](https://github.com/baoy21/moe-ub-cosim/blob/e20d42a2bcf0b2ac2529b8641a9492638ffc786f/backend/README.md#m42-交接队列与第三组竞争)，完整命令见 [历史环境记录](https://github.com/baoy21/moe-ub-cosim/blob/e20d42a2bcf0b2ac2529b8641a9492638ffc786f/docs/environment.md#2026-09-29m4-2-pd-queue)。本用例没有真实路由或目标计算 profile；数据导入另见[数据输入用例](../m4_data_inputs/README.md)。
