# 多来源消息缓冲准备验收

公开准备入口支持4..16份不同R1形状的来源文件，默认保持四份来源和旧限额。验证使用测试生成的合成路由，不是实际R1性能或新的网络执行。

`tests/unit/message_buffer_prepare_test.py`通过公开脚本检查默认人工示例、4/15/16份来源的分组/身份/累计额度，以及越界、无来源清单和来源数量不足。每次准备仍经过既有全服务验证，覆盖消息/备用连接、贡献数及确认记录额度。真实实验与包级验证另见当前任务，不将CPU准备成功当作网络完成。

命令及源文件身份见[验收摘要](receipt.json)，使用方式见[公开示例](../../examples/scaleout_message_buffers/README.md)。
