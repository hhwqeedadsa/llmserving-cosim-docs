# RDMA 数值观测记录的表示等价

逐包更新 JSON 的端口计数、流状态、路径与回调时间改为数值结构，在执行结束后构造 JSON。流与端点使用哈希查找，端口用向量索引，可达性使用有界矩阵；导出按逻辑身份排序。包、消息字节、协议、计算依赖和完成事件不变。

[evidence.json](evidence.json)保存实际检查：旧 8 卡、完整 16 卡、完整 128 卡均通过独立服务核验；对应 `result.json` 与任务图分别逐字节相同，图文件数为 36、34、258。四个当前源码 SHA-256 与 128 卡执行前来源记录一致；这证明被检查场景的表示改动保持结果，不替代硬件校准，也不外推未完成规模。

千卡新旧两版都触发预声明的 600 秒宿主限额。相关记录属于未完成运行，不作为正确性通过证据。部分运行同机重叠，时间数据只报告观测值，不宣称受控优化加速比。

比较程序位于[实验等价检查](../../experiments/scaleout_scaling/verify_invariance.py)，只读取公开产物。宿主时间与原始记录入口见[运行成本报告](../../experiments/scaleout_scaling/results/runtime_20261016/report.md)。源码与验证独立本地提交，研究实验另行提交。
