新增检查覆盖：首步完成不提交片段结果、不跳过备用；实际前驱完成驱动后步；最后一步提交唯一赢家；已启动输家继续完整执行；缺步/重步/错组/提前或滞后后步/首步冒充完整结果被拒绝；不同步数具有不同输入身份；真实LLMServingSim调度器在中间步保留备用KV，仅最后一步释放；旧格式继续拒绝多步。

多步通过显式replication/4准入，不放宽原格式。执行前检查不证明实际新网络已成功或研究收益。网络验收与研究对照分开记录；任何成功结果都必须保留全部原生图、阶段门限、接收/源确认与最终释放。
