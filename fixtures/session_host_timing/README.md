证据见[默认对照](default-equivalence.json)、[开启观测对照](timed-equivalence.json)、[失败解释](failure-analysis.json)、[总核验](verification.json)、[独立恢复](recovery.json)及[预算收尾](closeout.json)。完整原件与固定runtime/八库检查点保存于 `runs/session_host_timing_checkpoint_20261024/`。恢复只声称同主机Linux/ABI迁移，不是从零构建或GPU/provider校准；小例不能替代代表性完整调用。
