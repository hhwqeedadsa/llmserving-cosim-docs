# 源端确认期限的实际在线验收

实现固定于`14fc5713bd`。新增显式、一次性的源端确认期限，不改变原传输、门限、ACK或图退出。接口和可独立准备的输入见[文档](../../docs/source_ack_watchdog.md)、[公开128端点Clos示例](../../examples/scaleout_source_ack_watchdog/README.md)。

输入为四份不同人工路由、31数据活跃rank、两个EP64组、E256/Top8/H256、每rank每层4专家、两层两步。128端点、16服务器×8、8ToR/8Agg/4Core、168链路、单rail/plane、各层400G、每链路1us。不是完整R1、真实路由性能实验或GPU测量。保持已有SR和参考DCQCN，不宣称商用RoCE校准。

正常与局部短时故障各新运行一次：均62消息、128专家贡献、7669执行事件。正常0通知、62定时器取消；局部1通知、61取消；最终均62源确认、0pending timer、0未确认。局部只在前20us丢弃GPU6目的DATA，实际丢1包。`normal`与`local`分别表示正常/局部故障，后者不是本机执行。

局部消息2的实际SEND post为1.030us，20us期限在21.030us通知，此前已有1142条执行事件；接收回调83.058us，真实源确认85.060us。通知时故障窗已结束，通知仍只使用本地post与尚无确认的事实，不读取故障真值。64.030us后确认的间隔不能直接当可回收空间。

两组任务及排空103.852/175.778us，完整包事件2120/2126；去掉新增watchdog字段后，分别与前轮对应原生结果完全一致。原图、执行事件及贡献记录逐字节一致，只比较保存原件，不重跑旧成功网络。

13项新增、56项相关CPU检查，共69项不同检查通过。独立审核原始交错控制流及真实post/确认，核验没有通知变成DECIDE/COMMIT；迁移流程和旧默认关闭检查通过。7类篡改（错消息、提前、错前缀、重复、缺失、错摘要、混入故障真值字段）被拒绝；4类非法原生配置在读取topology/创建Fabric之前拒绝。数据已到但源确认未到仍可通知，通知不伪造任何完成；同刻期限/确认按实际处理顺序判定。

仅新增服务编译单元并隔离链接，复用已验ASTRA archive及原生库；旧输出hash不变，不构建依赖或改锁。预算为累计900受监控秒/新增512MiB、保留8GiB；CPU120秒/1GiB/地址2GiB，单次构建180秒/1536MiB/地址3GiB，两个native各60秒/1GiB/地址2GiB/5ms模拟/128MiB产物。零下载、安装、GPU或依赖修改。一次文档补丁因旧标题不匹配未应用，核对后修正；网络与运行检查无失败或重跑。
