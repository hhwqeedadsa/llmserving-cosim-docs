八个事前固定条件全部完成：主例、深度1信用反馈、聚合尾未发布、源保护冲突、原生命令整批拒绝、旧默认、旧explicit、复制Python源码/空cwd/搬迁运行时。三个预期失败保留完整前缀，不补成功；没有失败网络重跑。
