对应[规范](../../docs/tasks/switch_link_failure_spec.md)和[公开示例](../../examples/scaleout_link_failure/README.md)。基线`a89f007`；原生ns-3补丁`6088174`、ASTRA父指针`85fe17e`、LLMServingSim父指针`f5558a2`，仅本地保存，没有push或上游升级。关闭入口实际执行一套原生RDMA ns-3，不混链UB。

`audit.py`只读完整拓扑、配置、输入和原始结果，以实际TX→对端RX/丢弃逐次匹配，允许UID重复，独立重建队列积分、入口/出口/共享占用、已知故障的最短路、连续接收字节及最终ACK。当前检查器限单plane人工字节例、优先级3及不同关闭时刻，不声称覆盖所有拓扑和同刻故障排序。

`audit_persistent.py`核对持久实际NIC/源包/连续接收及ACK覆盖；事务根据捕获的MRT1源负载、真实到达和输入窗口独立解释，不导入平台的帧编码或内存实现。检查器目前只解析本例完整单包帧，不支持任意跨包MRT1；平台的跨包能力另有原有验收。

60项相关Python单元通过。18类非法列表分别经过Python及原生入口拒绝，包括“前项合法、后项非法”；原生拒绝位置在分配网络之前，未生成result。8类字节/MMU/路由/ACK篡改、5类持久完成/MRT1/分区篡改被拒绝，具体输入和摘要保存在本地检查点。

## 保留的失败与限制

最初构建在两文件成功编译后，因PATH没有Ninja而准备失败；改用已安装的绝对路径继续未完成步骤，没有安装或重复成功编译。首个100Gb/s故障例在关闭时没有排队，不能证明MMU清理，后补25Gb/s真实排队条件。

PFC最初输入262,144B低于公开1MiB下限，被CLI拒绝，原配置与失败保留；没有放宽平台下限，改为合法1MiB和较长消息形成流控。离线检查曾误读入队hook时点、将交换机转发ACK当作源反馈、误写源隔离字段；只修检查器并复算原件，未重跑成功网络。可迁移链接最初匹配命令时发生StopIteration，未启动构建进程，准备失败单独登记。永久分区是预期功能失败，不与这些准备/检查错误混称。

本增量解决网络失效建模和可证伪验证缺口；经典最短路改路、go-back-N及缓冲修复不构成论文主贡献。检测/分布式控制代价、NIC或rail故障、恢复上线、现代GIN/GPU生产者停止、应用恢复、匹配硬件校准、代表性负载和千卡完整执行仍缺失，整体研究目标继续进行。
