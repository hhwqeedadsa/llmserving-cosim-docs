关键结果
--------

* SimAI 总模拟时间为 7,545,619 μs；compute 60.20%、exposed communication 35.21%、
  bubble 4.59%。EP 与 DP_EP 合计占暴露通信 86.2%。
* Dense 单 GPU 的 TTFT/TPOT 为 12.598/11.262 ms；2-GPU MoE 为
  30.887/8.080 ms。
* MoE docstring 描述 AllToAll，但实际默认 trace 是
  ``AllReduce + AllGather + ReduceScatter``。
* SimCCL 将 8-rank AllToAll 展开为 56 条 512 KiB 流，总 payload 28 MiB。
* ns-3 中 56/56 task 完成，flow packet-envelope 中位数为 76.568 μs，device NIC
  active-window throughput 平均约 395.56 Gbps。
* task 0 的最后数据包到达、WQE completion 和 last-packet ACK 是三个不同事件，不能合并
  成一个“通信完成时间”。

证据边界
--------

当日工作证明了数据链、字节守恒和观测粒度可行，但没有 A100 实机网络测量。LLMServingSim
GPU profile 来自 RTXPRO6000；collective 单操作时间是 reconstructed；SimCCL flow 是
structural；ns-3 时间来自代表性单交换机模型。以上结果不能直接外推为生产集群性能。
