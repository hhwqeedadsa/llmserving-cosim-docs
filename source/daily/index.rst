每日更新规范
------------

每个有实际工作的日期创建或更新 ``source/daily/YYYY-MM-DD.rst``，至少记录：

1. 当日问题和实验配置；
2. 新增或修改的代码、数据、图和报告入口；
3. 关键数值及其数据来源、物理量、单位和证据类型；
4. 哪些结论已经验证，哪些仍是假设、重建或仿真；
5. 构建、测试、守恒检查和失败项；
6. 下一步最小可执行实验。

页面按日期组织不等于按日期复制完整专题报告。重复出现的方法和长期结论只在专题页维护，
每日条目使用 :doc:`../simai-llmservingsim-study` 等链接指向权威版本。
